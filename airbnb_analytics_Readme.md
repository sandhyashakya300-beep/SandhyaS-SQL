Airbnb Analytics SQL Project

📌 Overview

This project builds a small Airbnb-style analytics database using MySQL. It demonstrates how to design a dimensional-style data model with Hosts, Properties, Guests, and Bookings, populate the tables with sample data, and answer business questions using SQL joins, aggregation, filtering, grouping, and ordering.

The database is named airbnb_analytics. The schema separates descriptive dimensions from booking transactions, with fact_bookings acting as the central fact table. fileciteturn6file0L1-L39

🎯 Project Objectives

Create an Airbnb analytics database.

Design dimension tables for hosts, properties, and guests.

Create a booking fact table with foreign-key relationships.

Insert sample booking and customer data.

Analyze host booking performance.

Compare revenue by property type.

Analyze booking revenue across guest age groups.

Analyze bookings by guest nationality.

Identify properties with average ratings above 4.5.
